# Features Directory Structure

Thư mục `features/` tổ chức code theo domain modules cho Campus Marketplace:
- `features/auth`: Các components, hooks và services liên quan đến xác thực sinh viên.
- `features/catalogue`: Quản lý danh mục sản phẩm, tìm kiếm, lọc và cache offline-first.
- `features/cart`: Giỏ hàng sinh viên và quy trình hẹn điểm giao dịch.
- `features/favorites`: Danh sách đồ dùng đã lưu.
- `features/listing`: Quản lý chi tiết tin đăng và form đăng bán mới.
